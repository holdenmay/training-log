TRAINING LOG — FIRST PROTOTYPE

What works:
- Dark, mobile-first workout logger
- Exercise library with primary muscle groups
- Set-by-set weight and reps entry
- Completed-set tracking
- Previous performance shown while logging
- Workout history
- Weekly working-set and volume summaries
- Manual run and hockey entries
- Local storage and JSON backup/restore
- Offline shell after first load (when hosted over HTTPS)

Important:
- This is a prototype, not yet published or installed on your iPhone.
- Data is stored in the browser on the device. Export backups regularly.
- Garmin automatic sync is not connected yet. The next phase needs a secure backend.
- Never put your Garmin password or Personal API key into index.html or share it in chat.

To install:
1. Host these files on a free HTTPS static host such as GitHub Pages.
2. Open the hosted URL in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. Open the app from the Home Screen.

No paid libraries or external JavaScript dependencies are used.
